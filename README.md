# Bitrix24 AI Agent + MCP (коробка, закрытый контур)

ИИ-агент и MCP-сервер для **коробочного Битрикс24**. Работает с корпоративной LLM (например, Qwen) через **LiteLLM** и **не требует входящего доступа**: все соединения идут от агента к порталу и от агента к LLM.

- **Отдельный чат с агентом**: бот в мессенджере, личный диалог или @упоминание в групповом чате.
- **Чат по объекту**: агент работает в контексте сделки, контакта или элемента **смарт-процесса**. Чат можно привязать, создать или взять штатный чат CRM-карточки.
- **Комментарии в таймлайне**: агент отвечает на @упоминание в комментарии объекта или на все комментарии объекта, поставленного на отслеживание.
- **Переписка и документы**: письма из таймлайна, файлы объекта (поля, вложения комментариев, писем и дел на Диске) —
  читает PDF/DOCX/XLSX/PPTX/ODT/RTF/TXT/CSV/HTML/EML **по запросу** («что пишет клиент?», «разбери договор»)
  или **автоматически**: по новому входящему письму или файлу готовит справку (суть, запросы, риски, шаги,
  черновик ответа) в таймлайн и/или в личку ответственному.
- **Данные**:
  - сделки, лиды, контакты, компании, предложения, счета, **любые смарт-процессы**;
  - задачи, сотрудники и оргструктура, рабочие группы;
  - календарь, задания бизнес-процессов, универсальные списки;
  - любой другой метод через `bitrix_call` с политикой безопасности.
- **MCP-сервер** с тем же набором инструментов, около 40 (`b24agent tools`).
- **Расширяемость**: плагины в `plugins/` и переопределение встроенных инструментов. Подробно — в [docs/EXTENDING.md](docs/EXTENDING.md).

```
Сотрудник ─ чат / @упоминание ─► Битрикс24 (коробка)
                                   ▲  imbot.v2.Event.get (fetch), crm.item / timeline (опрос), REST
                                   │  — все запросы исходящие от агента —
                         b24agent serve ◄──► LiteLLM ◄──► Qwen
                         b24agent mcp   ◄──► MCP-клиенты (Claude Desktop, Cursor, …)
```

**Документация:**
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — что описывает и позволяет агент, каналы, компоненты, безопасность;
- [docs/EXTENDING.md](docs/EXTENDING.md) — как дорабатывать: плагины, контракт инструмента, тесты;
- [docs/BITRIX_BOX_API.md](docs/BITRIX_BOX_API.md) — справочник REST API коробки для MCP в закрытом контуре: что работает через вебхук, imbot.v2, CRM, задачи, ограничения, бэклог.

## Требования

- **Битрикс24, коробка:**
  - модули CRM, задач и мессенджера, с `crm.item.*` и смарт-процессами;
  - **imbot.v2** для режима fetch; это проверяет `b24agent check`;
  - для старых версий есть `BOT_API=v1`, но ему нужен входящий доступ к агенту;
  - REST доступен по лицензии или подписке.
- **Python 3.11+** или [uv](https://docs.astral.sh/uv/).
- **Сеть:** агент → портал по HTTPS, агент → LiteLLM.

## Установка

```bash
git clone https://github.com/rusnetru/bitrix24-mcp.git && cd bitrix24-mcp
uv sync            # или: pip install -e .
cp .env.example .env
```

1. **Сервисный пользователь и вебхук.**
   - Заведите пользователя «ИИ-агент» с нужными правами CRM и задач.
   - От его имени создайте входящий вебхук: **Разработчикам → Другое → Входящий вебхук**. Права: `crm`, `task`, `user`, `imbot`, `im`, `department`, `sonet_group`, `calendar`, `bizproc`, `lists`.
   - Комментарии в таймлайне и задачи агент создаёт от этого пользователя, а его права ограничивают агента.
   - Если у портала самоподписанный сертификат, укажите `BITRIX_VERIFY_SSL=/path/ca.pem`.
2. **LLM:** задайте `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` (имя модели в LiteLLM).
   - `LLM_TOOL_MODE=auto` использует нативные tool calls. Если прокси их не поддерживает, агент переходит на JSON-протокол. Он также понимает `<tool_call>…</tool_call>`, которые Qwen пишет текстом без парсера.
   - Для Qwen3 можно отключить «размышления»: `LLM_EXTRA_BODY={"chat_template_kwargs":{"enable_thinking":false}}`.
3. **Проверка, регистрация и запуск:**

```bash
uv run b24agent check     # вебхук, права, imbot.v2, REST 3.0, LLM и поддержка tools
uv run b24agent tools     # список инструментов (встроенные + плагины)
uv run b24agent ask "сколько открытых сделок у пользователя 1?"
uv run b24agent setup     # регистрирует бота imbot.v2 (eventMode=fetch)
uv run b24agent serve     # агент: забирает события бота, сканирует таймлайны
```

Для постоянной работы запустите `b24agent serve` как службу: systemd, NSSM или Docker.

### Письма и файлы

- По запросу: «какая переписка с клиентом по проекту 15?», «прочитай договор во вложении и выпиши сроки и штрафы»,
  «подготовь ответ на последнее письмо». Инструменты: `crm_emails`, `crm_email_read`, `crm_files`, `file_read`.
- Автоматически: `AUTO_ASSIST_TYPES=1038,deal` — агент находит элементы с новой активностью и по каждому новому
  входящему письму / файлу в комментарии готовит справку. Куда: `AUTO_ASSIST_TARGET=timeline,chat`.
  Что готовить — свой регламент в `AUTO_ASSIST_PROMPT_FILE`. Автоматический режим всегда **только читает**.
- Ограничения: размер файла `FILES_MAX_MB` (25 МБ), сканы и картинки без текстового слоя не читаются (нужен OCR —
  подключается плагином), старые `.doc/.xls` — нужен конвертер. Текст файлов кэшируется в `DATA_DIR`.

### Таймлайн без входящего доступа

Через входящий вебхук нельзя подписаться на события (`event.bind` → `WRONG_AUTH_TYPE`). Исходящие вебхуки коробки идут через облачную очередь Битрикс24. Поэтому таймлайн читается опросом:

- `TIMELINE_SCAN_TYPES=deal,1038`: раз в `TIMELINE_SCAN_INTERVAL` секунд агент находит элементы этих типов с новой активностью (`lastActivityTime`) и отвечает на комментарии с @упоминанием бота или сервисного пользователя;
- `TIMELINE_POLL_INTERVAL=30`: опрос объектов, которые сотрудники поставили на отслеживание («следи за таймлайном сделки 123»).

## Как пользоваться

- **Личный чат:**
  - «Мои задачи на неделю»;
  - «Найди контакт Иванов и его сделки»;
  - «Переведи сделку 123 на стадию „Договор“»;
  - «Что мне на согласование?»;
  - «Когда свободны Петров и Сидоров в четверг?».
- **Чат по объекту:**
  - «привяжи этот чат к проекту 15» или «создай чат по сделке 123»;
  - либо добавьте бота в штатный чат карточки;
  - в групповых чатах обращайтесь через @упоминание.
- **Таймлайн:**
  - `@ИИ-агент какая стадия и что по задачам?`, и агент отвечает комментарием;
  - «следи за таймлайном сделки 123», и агент отвечает на все новые комментарии.
- **Команды:** `/help`, `/clear` (очистить историю диалога), `/context` (к чему привязан чат).

## Безопасность (кратко)

| Настройка | Действие |
|---|---|
| `AGENT_ALLOW_WRITE=false` | режим только чтения |
| `AGENT_ALLOWED_USERS=1,15` | кому можно общаться с агентом |
| `TOOLS_DISABLED=bp_start,crm_add` | точечно отключить инструменты |
| `BITRIX_CALL=off\|read\|full` | политика универсального вызова; по умолчанию `read` (только читающие методы) |
| `EVENT_SECRET` | защита HTTP-приёмника, если используется push |

Подробно — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#безопасность).

```json
  }

```

Настройки читаются из `.env` в каталоге проекта.
